# Vision-Based Stress Detection Using Eyebrow Features

## Project Overview

This project presents a computer vision framework for detecting stress in students during programming activities by analyzing eyebrow features instead of the entire face.

The proposed system uses a two-stage classification approach and compares traditional machine learning models with deep learning models.

---

## Features

- Eyebrow-based stress detection
- Two-stage classification
- Stress vs Non-Stress
- Low, Moderate and High Stress Classification
- Lightweight real-time framework
